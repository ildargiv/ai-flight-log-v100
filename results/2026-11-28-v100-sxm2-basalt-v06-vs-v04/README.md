# 2026-11-28 · V100 SXM2 32 GB · Basalt v0.6 vs v0.4

Сырьё к записи [`journal/entries/020.md`](../../journal/entries/020.md).

## Что мерили

Обновление движка Lapilli/Basalt с backup-бинарника `v0.4` (`bin/basalt.v0.4.backup`, 234 МиБ)
до `v0.6.0-v100.1` (`bin/basalt`, 255 МиБ, коммит `6f0a1e6b`, сборка CUDA 12.9 / gcc-14 / sm_70 /
`BASALT_MODELS=qwen4exp`). Одна и та же модель `Qwen3.8-FN-UD-Q4_K_XL.basalt`, 262k service config.

Схема **ABBA**, полный cold restart движка между прогонами:

| прогон | бинарник | файл |
|---|---|---|
| A1 | new v0.6 | `bench-A1.md` |
| B1 | old v0.4 | `bench-B1.md` |
| B2 | old v0.4 | `bench-B2.md` |
| A2 | new v0.6 | `bench-A2.md` |

Команда:

```
basalt-bench --model /home/omarchy/build/lapilli-v100/models/Qwen3.8-FN-UD-Q4_K_XL.basalt \
  --engine <new|old> -t conv,struct,prose -p 16384,32768,65536,131072 \
  --seed 1 -r 1 --logs bench-<arm>-logs
```

`full-compare.log` — полный вывод оболочки сравнения. `smoke-v06.log` — лог короткого HTTP-теста
на новом бинарнике (`PONG v06`). `results.json` — machine-readable сводка.

## Ограничения

- `-r 1`: внутри плеча decode имеет только одно повторение. Для вывода нужно `-r 4`.
- bench запускается с `--max-context 133249`, сервисный конфиг — `262144`.
- Новый бинарник собран только с `qwen4exp`; Inkling/Hy4 требуют отдельной пересборки.
- Не якорь (квант, линейка движка и хост отличаются от якорной линии).
