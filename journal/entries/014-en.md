### Unsuccessful

- **class: operator** — `strata bench run --profile iq3_s` fails: the installed run config
  is not a saved profile.
  - how to recognize it: `strata: profile 'iq3_s' is not saved; use strata profile create`
  - what to do instead: `strata profile create NAME --from-config strata-iq3_s.json`
- **class: harness** — `strata bench compare` does not accept standard-v1 reports.
  - how to recognize it: `strata: unsupported benchmark report` (the validator expects a serving
    suite with `phases`)
  - what to do instead: compute deltas from `results.json`, `summaries` block (that is what was done).
- **class: harness** — the 4th decode A/B round, run separately after a pause, gave the
  **opposite** result: B lost 4/4 (chat0 64.4 vs 67.9). The first arm after idle apparently pays
  for a cold model cache: 78 GB does not fit into 64 GiB of RAM.
  - how to recognize it: across three alternating rounds B wins 11/12 pairs, while the first round
    after a pause loses everything
  - what to do instead: discard a cold round as warm-up; keep the decode magnitude as an
    observation (RULES #5), not an anchor.
- **class: harness** — in the switch-arm standard run the third repetition sagged: decode 16k
  46.1 tok/s, prefill 1240 against 1619 in the first round. Cause not established: there was no
  throttling (237/250 W, ≤82 °C), expert cache 92–98%.
  - how to recognize it: the median smooths it out, but min–max splits by a factor of two
  - what to do instead: do not rely on a single protocol run for decode.

### Conclusion

The recipe transfers to a PCIe card unchanged. `PF_WMMA` gives **+5.5% prefill** — less than the
logged +9.4%, probably because of IQ3_S packing: the FP16 path touches a smaller share of layers,
so the gain is proportionally smaller; power is not the reason. The decode core gives **+5–7%**
on alternating rounds, but its magnitude depends on the state of the model cache; on the long
prompt at n=4 it stays +2.6% (within noise per RULES #5). `PF_WMMA` on this model and packing
changed none of the 24 answers. Everything is enabled in the main run config; the release anchor
stays stock.

Unexplained: the third-repetition sag in the standard run and the reversed 4th decode A/B round
(both look like a cache/machine state effect rather than a property of the switches).
