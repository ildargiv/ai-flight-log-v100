## O-022 — 2026-11-23 — smoke/benchmark — Inkling-2-Mini UD-IQ1_S mainline (llama.cpp) on V100 SXM2

Дата: 2026-11-23
Класс: `smoke`, `benchmark`, `config`
Железо: Tesla V100-SXM2-32GB (sm_70, 32GB), Xeon E5-2673 v3 (24 vCPU), 125GB RAM, Omarchy Linux 7.2.15-1-omarchy
Движок: `llama-server b12648` (CUDA 12.8 build), mainline GGUF, full GPU offload
Модель: `Inkling-2-Mini-UD-IQ1_S-mainline.gguf` (7.3G, UD-IQ1_S), alias `inkling-2-mini-ud-iq1s-mainline`

Конфиг запуска:
- `llama-server -m /home/omarchy/Models/_tmp/Inkling-2-Mini-UD-IQ1_S-mainline.gguf -ngl 99 -c 32768 --host 0.0.0.0 --port 8081 --alias inkling-2-mini-ud-iq1s-mainline --jinja`
- `LD_LIBRARY_PATH` включал CUDA 12.8 llama.cpp libs + CUDA 12.9 targets libs.

Что мерили:
- Smoke throughput/latency: ~1k/4k/16k prompt tokens (actual 1115/4334/17294 med), 3 runs/arm.
- `temperature=0`, `max_tokens=128`, `stream=false`, fresh nonce per request, warmup excluded.
- Timings from llama.cpp `timings` (`prompt_per_second`, `predicted_per_second`, `prompt_ms`) and `usage`.

Наблюдения:
- 1k run1 prefill 43.62 tok/s — холодный/прогревочный outlier; runs2/3 655.20/634.14 tok/s. Для prefill выводов run1 исключать.
- 1k run2 имеет `cached_tokens=13` при свежем nonce — небольшой cache artifact; остальные прогоны `cached_tokens=0`.
- Decode стабилен: ~35.02 / 32.49 / 31.23 tok/s median по arms.
- GPU во время 16k arm: ~100% util, ~13.2GB/32GB VRAM, ~209W.

Ограничения:
- Это smoke/observation, **не anchor** и не сравнение с DeepSeek/Qwen anchor линиями (другая модель/движок/квант/правила).
- TTFT client-side не замерялся отдельно; `prompt_ms`/`predicted_ms` — engine timings llama.cpp.
- IQ1_S — очень агрессивный квант; скорость/качество не репрезентативны для более высоких GGUF квантов.
