### Конфиг прогонов

Базовый прогон:

```bash
basalt-bench --model /home/omarchy/build/lapilli-v100/models/Inkling-2-Mini-NVFP4-DQ8.basalt \
  --engine bin/basalt --fixtures data/bench/inkling2 \
  -t conv,struct,prose -p 16384,32768,65536 \
  -r 4 --depth-decode 64 --seed 1 --logs /home/omarchy/inkling-bench-logs \
  --kv fp16 --vram-reserve-mib 700 --gpu 0 -o json
```

Глубокий prefill:

```bash
basalt-bench --model /home/omarchy/build/lapilli-v100/models/Inkling-2-Mini-NVFP4-DQ8.basalt \
  --engine bin/basalt --fixtures data/bench/inkling2 \
  -p 131072,262144,524288 \
  -r 2 --depth-decode 64 --seed 1 --logs /home/omarchy/inkling-deep-logs \
  --kv fp16 --vram-reserve-mib 700 --gpu 0 -o json
```

### Наблюдения

- **Decode совпал с README.** conv 121.19 tok/s (README 121), struct 215.72 tok/s (README 214), prose 101.63 tok/s. Draft acceptance: conv 67.54% / len 1.59, struct 97.74% / 5.48, prose 50.98% / 1.22.
- **Prefill ниже README на ~7–9% на 16k/32k.** 1427 tok/s @16k (README 1567), 1352 @32k (README 1459), 1218 @64k. Разное железо/драйвер/состояние машины; трактую как наблюдение, не как регрессию.
- **512k prefill работает на 1×V100 32GB.** 131072: 1019 tok/s; 262144: 680 tok/s; 524288: 467 tok/s (mean, n=2). Decode после prefill: 57.7–61.7 / 44.6–48.4 / 26.3–25.7 tok/s. OOM не было; при 512k GPU ~31.7 GiB, эксперты частично в RAM.
- **Сервер/API проверен.** `/health` loaded=true, `/v1/models` отдаёт `Inkling-2-Mini` ctx=65536, chat completion отвечает, tool call (`get_weather`, Paris) возвращает `finish_reason=tool_calls`. Сервер поднят с `--host 0.0.0.0` для доступа по Tailscale.

### Наблюдения (class: измерение)

- **Глубокий прогон — n=2, базовый — n=4.** Для 512k это компромисс по времени/нагрузке; stddev мал (0.88 tok/s на 512k prefill), но для строгого сравнения нужен больший n.
  - Факт: команды с `-r 4` (базовый) и `-r 2` (глубокий).
  - Что делать: при сравнении с другими сборками повторять тем же n/seed/fixtures.
- **Decode после prefill взят из progress log, не из отдельного summary поля.** `basalt-bench` печатает `then 64 tokens written at X tok/s`, но в summary JSON эти значения не агрегированы как отдельная метрика.
  - Факт: строки в `inkling-bench-progress.log` и `inkling-deep-progress.log`.
  - Что делать: при автоматической обработке парсить progress/result records или добавить явный экспорт.
